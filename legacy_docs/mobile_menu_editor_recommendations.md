# Mobile Menu Editor UX Improvements

Prepared for: Antigravity Development Team

## Overview

The mobile version of the menu editor is improving, but there are still
critical usability issues that prevent effective editing on smaller
screens. The current interface places large control panels over the
canvas, making it impossible to see or precisely edit the menu elements
underneath.

The goal of these improvements is to transform the mobile editor into a
**modern touch‑based design interface**, similar to professional mobile
design tools such as Canva or Adobe Express.

------------------------------------------------------------------------

# Core Problem

Currently:

-   Editing controls cover most or all of the menu canvas
-   Users cannot clearly see the element they are editing
-   There is no efficient way to zoom into small text
-   The UI behaves like a **desktop toolbar compressed into a mobile
    screen**

For mobile usability, the **menu canvas must remain the primary visible
element**.

------------------------------------------------------------------------

# Required UX Principles

1.  The menu canvas must always remain visible while editing
2.  Controls should occupy **no more than 20--30% of the screen**
3.  The interface must support **touch-first interactions**
4.  Editing controls must be **compact, modern, and collapsible**
5.  Users must be able to **zoom, pan, and precisely select elements**

------------------------------------------------------------------------

# Feature 1: Full Canvas Editing

The menu canvas should take up the entire screen when editing.

Key functionality:

-   Pinch-to-zoom (up to 300--400%)
-   Drag/pan navigation
-   Tap to select text
-   Smooth touch gestures

Behavior should feel similar to interacting with a map interface.

Example Layout:

    --------------------------------
    |                              |
    |          MENU CANVAS         |
    |                              |
    |                              |
    |                              |
    |                              |
    |                              |
    |                              |
    --------------------------------

------------------------------------------------------------------------

# Feature 2: Floating Action Button (Primary Controls)

Instead of a large control header, use a single floating action button.

Example:

                               ⚙
                            (edit)

When tapped:

                               ⚙
                            Edit Tools
                          ───────────
                          Text
                          Font
                          Move
                          Delete

Benefits:

-   Canvas remains visible
-   Controls are easily accessible
-   Minimal screen obstruction

------------------------------------------------------------------------

# Feature 3: Bottom Editing Toolbar

When a text element is selected, a **small bottom toolbar** should
appear.

Example:

    --------------------------------
    | Font ▼ | Size - 16 + | Space |
    --------------------------------

Controls may include:

-   Font selection
-   Size adjustment
-   Letter spacing
-   Delete text

Toolbar should occupy **minimal vertical space**.

------------------------------------------------------------------------

# Feature 4: Collapsible Bottom Panel

For additional tools, a collapsible panel can appear from the bottom.

Example:

    --------------------------------
    |          MENU CANVAS         |
    |                              |
    |                              |
    |                              |
    |------------------------------|
    | Edit | Text | Save | Export  |
    --------------------------------

Panel height should remain **under 25% of the screen**.

------------------------------------------------------------------------

# Feature 5: Snap Zoom Editing

This feature dramatically improves mobile editing precision.

Workflow:

1.  User taps a text element
2.  Canvas automatically zooms to that element
3.  Element is centered on screen
4.  Editing controls appear below

Example:

Before tap:

    Catfish 3 pieces  $15.99

After tap (auto zoom):

    ------------------------
    |                      |
    |   Catfish 3 pieces   |
    |        $15.99        |
    |                      |
    ------------------------

Benefits:

-   Eliminates manual zooming
-   Faster editing
-   More accurate text selection

------------------------------------------------------------------------

# Feature 6: Text Selection Highlighting

When text is selected, it should display a visible bounding box.

Example:

    ┌──────────────────────┐
    | Catfish 3 pieces     |
    | $15.99               |
    └──────────────────────┘

Optional additions:

-   Drag handles
-   Resize handles
-   Selection glow

Benefits:

-   Clear visual feedback
-   Users know exactly what element is selected

------------------------------------------------------------------------

# Feature 7: Modern Mobile UI Styling

Controls should match modern UI standards:

-   Rounded buttons
-   Subtle shadows
-   Smooth hover/touch states
-   Color palette matching the menu theme
-   Minimalist design

Avoid:

-   Large desktop-style button panels
-   Full-screen control overlays

------------------------------------------------------------------------

# Ideal Mobile Editing Workflow

1.  Open editor
2.  Menu canvas appears full screen
3.  User pinch-zooms to area of interest
4.  User taps text element
5.  Canvas auto-zooms (Snap Zoom)
6.  Element highlights with selection box
7.  Small editing toolbar appears
8.  User edits text
9.  Tap outside element → zoom out

This keeps the editing experience fast, intuitive, and mobile-friendly.

------------------------------------------------------------------------

# Final Goal

The mobile editor should feel like a **modern touch-based design
application**, not a desktop interface forced into a mobile screen.

Key outcomes:

-   Canvas always visible
-   Easy zoom and navigation
-   Compact editing tools
-   Precise text editing

This approach will significantly improve usability and make the editor
feel like a professional SaaS design tool.

------------------------------------------------------------------------

# Summary

Critical improvements needed:

-   Full-screen canvas editing
-   Pinch-to-zoom and drag navigation
-   Floating controls instead of large panels
-   Snap zoom editing for text elements
-   Visible text selection highlighting
-   Modern mobile UI styling

These changes will make the mobile editor significantly easier and more
efficient to use.
