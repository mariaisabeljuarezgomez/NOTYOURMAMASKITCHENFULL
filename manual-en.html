1. Welcome & Introduction

Welcome to Menu Editor Pro V2, the most advanced browser-based menu editing system specifically tailored for high-end restaurant displays. This version has been completely re-engineered for speed, precision, and cross-device reliability.

Whether you are using a desktop computer for fine-tuning your layout or a mobile phone for quick price updates in the kitchen, Menu Editor Pro V2 provides a professional, "what-you-see-is-what-you-get" (WYSIWYG) experience without requiring any design or coding skills.

2. What Is New in V2?

Version 2 introduces critical architectural changes and high-end features designed for professional restaurant environments:

  • Native Canvas Rendering: All elements are now rendered using the browser's native Canvas API for pixel-perfect fidelity and smooth performance.
  • Server-Side Persistence: Your progress is now saved to a secure PostgreSQL database. Changes persist across reloads and different devices.
  • Advanced Undos: A robust, multiple-step undo system protects your work against accidental mistakes.
  • Mobile UX Hardening: Every button, slider, and gesture has been optimized for touch screens, with multi-touch suppression and mobile-friendly toolbars.
  • Cloud Asset Tray: All uploaded images are served via Cloudinary global CDN, ensuring your menu loads instantly anywhere in the world.

3. Before You Start

Internet Connection: Menu Editor Pro V2 is a web application. You must be connected to the internet to save your changes and upload new images.

Supported Browsers

The editor works on all modern browsers. We recommend Google Chrome or Apple Safari for the most consistent experience. Please ensure your browser is updated to the latest version.

Screen Orientation

If you are on a mobile device or tablet, we highly recommend using Landscape mode (turning your device sideways). This provides more workspace and makes the toolbar controls easier to manage.

4. Editor Layout Anatomy

The editor is divided into four main functional areas. Understanding these areas will help you navigate the system quickly.

1. The Canvas (Center)

Your menu board. This is where you see your design exactly as it will appear once exported. You can click any element to edit it.

2. Header Bar (Top)

Contains global controls: 💾 Save, ↺ Undo, 🏠 Home, and the current layout state (Locked/Unlocked).

3. The Tools Drawer (Left)

Opened by the 🛠️ Floating Action Button (FAB). Contains the ADD tab for new elements and the ASSETS tab for your images.

4. The Selection Bar (Floating)

Appears only when an element is selected. Shows three tabs: 🏷️ LAYER, 🎨 DESIGN, and 📐 ARRANGE for fine-tuning the selected object.

5. The Quick-Start Guide (5 Minutes)

Follow these steps to make your first update in under five minutes:

  1. Unlock: Click the 🔒 Layout Locked button in the top bar to switch to 🔓 Unlocked mode. This allows you to click and select elements.
  2. Edit Text: Double-click any price or item name on the canvas. A cursor appears. Type your new values. Click the background to finish.
  3. Move Elements: Single-click any element, then drag it to a new position. Use the ARRANGE tab for centering.
  4. Upload Logo: Click the 🛠️ FAB (bottom left) → Upload Img. Select your file. It appears on the canvas automatically.
  5. Save: Click the 💾 Save button in the top bar. Your changes are now permanent and stored on the server.
  6. Export: Click the 🛠️ FAB → ⬇️ Export Pro PNG. Your print-ready menu downloads immediately.
Pro Tip: Always keep the layout Locked unless you are specifically moving elements. In Locked mode, you can still edit text by double-clicking, but you won't accidentally drag elements out of place.

6. The Top Header Bar

The header bar is always visible at the top of your screen. It provides the core safety and management controls for your session.

🔒 Layout Lock / 🔓 Layout Unlocked

This is the most important control in the editor. By default, the layout is Locked. In this state, you can not drag elements or accidentally click small objects. This is "Safe Mode." Switch to Unlocked only when you need to reposition things or use the selection tabs.

💾 Save

Saves your entire session — all text content, positions, styles, layer settings, and image placements — to the server. Also creates a local browser backup simultaneously. A green toast message confirms: "Project Saved Locally". Use Save frequently. Auto-backup runs automatically every 5 minutes whenever unsaved changes exist. The Save button turns red when changes are pending. Auto-backup saves silently to the server — you will see a brief "Auto-backup saved" notification when it fires..

Shortcut: Save runs automatically every time you click Export Pro PNG, so your export always matches your most recent work.

↺ Undo Last Change

Reverses your most recent action one step at a time. The undo system remembers up to 50 actions, covering text edits, element moves, style changes, additions, deletions, visibility changes, and lock toggles. Click repeatedly to step back through history.

Important: Undo does NOT reverse a Reset to Original or a Load Session. Once you reload or reset, the history is cleared.

🏠 Home

Returns you to the application home dashboard. Always save before clicking Home.

↺ RELOAD

Refreshes the current application. Use this if the editor feels slow or if an action becomes unresponsive. This is more reliable than the browser's refresh button because it maintains the current editor context.

7. The Floating Action Button (FAB) & Drawer

The 🛠️ Floating Action Button sits at the bottom-left of your screen. Clicking it opens the System Drawer, which contains two primary tabs: ADD and ASSETS.

8. ADD Tab (The Tools Drawer)

This tab contains the buttons for adding new content to your menu and performing global file operations.

＋ Add Text

Creates a new text element in the center of your current view, labeled "New Text," already selected. Immediately type your content and use the Selection Bar to style it.

⬜ Add Rect

Creates a new rectangle shape in the center of the canvas. Use the DESIGN tab to change fill color, corner roundness, border width, and border color. Ideal for price backgrounds, banners, and dividers.

Add Circle — Adds a filled circle shape to the canvas. The circle is fully editable: change fill color, stroke, opacity, rotation, and size. Select it and use the DESIGN tab to style it.

Add Star — Adds a five-point star shape rendered as an SVG polygon. Fully styleable with fill color and stroke. Use the DESIGN tab after selecting.

Add Line — Adds a straight horizontal line element. Use the DESIGN tab to set line weight (0.25px to 4px), line cap style (Flat, Round, Square), and color. Lines can be rotated with the rotation slider.

🖼️ Upload Img

Opens your device's file picker. You can select multiple image files at once — hold Ctrl (Windows) or Cmd (Mac) while clicking in the file picker to select several images. All selected images will be imported into your asset tray simultaneously. The image is saved to your permanent library, appears in the Asset Tray, and is placed on the canvas automatically. Transparent PNG borders are auto-trimmed.

👁️ Toggle Original BG

Fades out the background image, showing only your elements on a dark grid. This is helpful for seeing small text or checking alignment. This setting is saved with your session.

🖼️ Replace Background

If you select an image element on the canvas, the drawer will show a "Replace Background" button. Clicking this promotes your selected image to become the new, locked master background for the menu.

Remove Background — Found in the Layers panel context. This permanently deletes all background layers from the canvas without replacing them. Use this when you want a transparent or blank canvas behind your content. This is different from Replace Background — it does not import anything new.

⬇️ Export Pro PNG

Generates a print-ready PNG at full resolution. Auto-saves first, then renders every visible element and downloads the file. A progress toast appears during export. Covered in full in Section 19.

🔄 Reset to Original

Clears ALL your custom edits and restores the menu to the original template delivered by Marias Digital Designs. Use with caution — this cannot be undone.

17. Selection Bar — ARRANGE Tab Deep Dive

The ARRANGE tab controls the Position, Stacking Order, and Alignment of your elements. Precision here makes the difference between a amateur and professional looking menu.

Stacking Order (Z-Index)

Determines which elements are "in front" and which are "behind."

  • Bring to Front: Moves the element to the absolute top of the stack.
  • Send to Back: Moves the element to the absolute bottom (just above the background).
  • Forward/Backward: Moves the element one layer at a time.

Precision Alignment Tools

When two or more elements are selected (Multi-select), these distribution tools appear:

Tool What It Does
↔️ Horizontal Distribute Equally spaces the gaps between elements from left to right.
↕️ Vertical Distribute Equally spaces the gaps between elements from top to bottom.
Align Left / Right Snaps all selected elements to the leftmost or rightmost edge of the lead element.
Align Center Line up the vertical centers of all selected items — perfect for price lists.
Perfect Price Lists: Multi-select your entire column of prices, then click Align Center (Vertical) and Vertical Distribute. This creates a perfectly spaced, straight vertical column automatically.

Rotation

Use the rotation slider or the degree input (0 to 360) to tilt elements. This is great for "New!", "Special!", or "Try This!" badges to give them a dynamic, hand-placed look.

18. Selection Bar — DESIGN Tab Deep Dive

The DESIGN tab controls the Visual Aesthetics of elements. This is where you set the mood of your menu.

Fonts and Typography (Text Only)

The font selection menu is populated with high-end typography carefully selected for restaurant use: Bernard MT Condensed, Century Gothic (Bold/Regular/Italic), and other clean, legible options.

Color Management

The color picker allows for Hex codes or visual selection. Each menu has a designated "Brand Palette" — try to stay within this palette for a cohesive look.

Text Spacing

  • Line Height: Increase the vertical gap between lines of text in descriptions.
  • Letter Spacing: Increase for headers to create an elegant, airy look.

Shape Design (Rectangle Only)

  • Fill: Primary color of the block.
  • Border: Set border color and thickness (0 to 20px).
  • Rounding: Turn a square rectangle into a pill-shape or circle by increasing this value.

Contrast Rule:

If your background is dark, use light text. If your background is light, use dark text. High contrast ensures highest legibility in low-light restaurant settings.

20. Troubleshooting

Most issues can be solved with these quick checks:

Elements are moving when I try to scroll

Solution: The layout is Unlocked. Click the 🔒 Locked button in the header to return to scroll-safe mode.

I can't see the text format settings

Solution: You must select a text element first. The DESIGN tab only shows font and color settings when something is selected.

An image I uploaded has a white box around it

Solution: To remove borders, use PNG files with transparent backgrounds. If your file is a JPG, the background is baked-in. Marias Digital Designs can help you convert your logo to a transparent PNG if needed.

The Undo button didn't fix my text change

Solution: If you are still actively typing (the cursor is inside the text), Ctrl+Z/Undo will undo individual characters. Once you click outside the text to finish, Undo will revert the entire text change.

The editor looks broken on my mobile screen

Solution: Turn your device sideways (Landscape mode). Mobile screens are too narrow in portrait mode to show the full canvas and toolbars comfortably.

Internet Warning: If the 💾 Save button turns red and gives a "Save Failed" error, check your internet connection. The editor will try to backup your work locally, but do not close the browser until you see the green "Project Saved" success toast.

22. Cloudinary & AI Video Creation

Menu Editor Pro V2 integrates with Cloudinary and AI video technology to create cinematic backgrounds for your menu.

What is Cloudinary?

Cloudinary is a global content delivery network (CDN). When you upload images or create AI videos, they are stored on Cloudinary's servers. This ensures your menu loads fast for everyone, everywhere.

Generating AI Video

  1. Open the ✨ AI Studio tab in the right-side panel.
  2. Enter a Video Prompt (e.g., "Steam rising from a fresh pizza, slow cinematic panning, golden lighting").
  3. Choose the Aspect Ratio (16:9 for landscape displays).
  4. Click Generate AI Video.
  5. When ready, the video is downloaded and saved to your project

Technical Details

  • API: Cloudinary's AI Video generation API
  • Library: cloudscraper — handles API requests server-side
  • Credentials: Cloudinary API key, secret, and cloud name are read from environment variables
  • Async: Generation is asynchronous; status is polled until the video is ready
  • Output: Downloaded MP4 video saved to the project directory

Configuration

Set the following environment variables before using AI video features:

  • CLOUDINARY_API_KEY
  • CLOUDINARY_API_SECRET
  • CLOUDINARY_CLOUD_NAME
Creative tip: AI video generation works best with specific, descriptive prompts. Describe the mood, camera movement, lighting, and subject clearly for the best results.

23. Save, Load & Auto-Save Deep Dive

Data safety is the foundation of Menu Editor Pro V2. This section details the multi-layer saving system.

Server Save (The "Primary" Save)

When you click the 💾 Save button, the entire state of your menu (the `docV2` JSON object) is sent to the PostgreSQL database on Railway. This is the **authoritative source of truth**. Once a server save succeeds, your data is safe even if you switch browsers or computers.

Auto-Save Protection

If you leave the editor before clicking Save, the system maintains a **Local Browser Backup** in your browser's `localStorage`. When you return to the editor, it will check if your local version is newer than the server version. If it is, a prompt will ask if you want to restore your unsaved changes.

Validation and Security

The system performs a full validation check before every save. It ensures that no invalid elements are added and that the file size remains within the 5MB performance limit. If a save fails, the editor will highlight the invalid areas and provide instructions on how to fix them.

Pro Tip: After a session, always click 💾 Save and wait for the "Project Saved Locally" toast BEFORE closing the tab. Never rely purely on auto-save if you are switching to another device.

24. Undo History

The ↺ Undo Last Change button (top header bar, or press Ctrl+Z) steps back through your editing history one action at a time. The undo system tracks up to 50 actions.

What Undo Covers

  • Text content edits
  • Element movement and resizing
  • Design changes (fonts, colors, spacing)
  • Adding or deleting elements
  • Visibility/locking/opacity changes
  • Rotation adjustments

What Undo Does NOT Cover

  • Save/Load: You cannot undo a "Load Session" operation back to its previous state.
  • Reset to Original: Reseting the template is permanent and cannot be reversed by Undo.

25. Export Pro PNG – Complete Reference

Generating the final menu image is a three-step process handled automatically by the editor's internal rendering engine.

The Export Pipeline

  1. State Capture: The editor first saves your current project to ensure the output matches your last edit.
  2. High-Fidelity Render: The system creates a hidden, high-resolution canvas. It loads the master background (3600px wide) and draws every element at 300% zoom level to ensure maximum crispness.
  3. CRC32 Checksumming: The PNG file is assembled with specific metadata chunks to ensure it is recognized as a 300 DPI professional file by printers and digital signs.

Export Output Specifications

Output File FormatPNG (Lossless)
Color ModesRGB (8-bit color)
Resolution (DPI)300 DPI (High Res)
Total Resolution (Pixels)3600w × 5400h

Export dimensions: 3600 × 5400 pixels at 300 DPI (12 × 18 inches print-ready). The exported file is named notyourmamaskitchen-menu.png.

Common Export Questions

Is the export different on mobile? No. The export engine is server-synced and uses the same high-resolution logic regardless of the device your are using to trigger the export.

Can I export a transparent menu? Only if you have removed the background layer entirely in the Layers panel. Otherwise, the menu will include the background frame.

Wait for the Finish: During export, a progress bar appears. Do not click anything until the file download actually begins. On slow connections, rendering the high-res frame can take up to 20 seconds.

28. Zoom & Canvas Navigation

Managing your view is critical for both laptop and mobile users. The editor includes a high-performance viewport controller.

Zoom Controls

Controls are located at the bottom-right of the screen:

  • Fit to Screen: Snaps the canvas to fit perfectly within your current window size. This is the default view.
  • ＋ Zoom In: Magnifies the canvas. This is required for reading and editing small font sizes (10-14px) and for precise placement of elements.
  • － Zoom Out: Shrinks the canvas view. Useful for seeing the whole menu at once.

Zoom Memory: Zoom level resets to fit-to-screen each time the page reloads. Use the zoom controls to re-adjust after reload.

Pinch Zoom on Mobile

On touchscreen devices, use a two-finger pinch gesture to zoom in and out on the canvas. Pinch zoom only works when the layout is Unlocked. Multi-touch is automatically suppressed to prevent accidental drag while pinching.

Canvas Panning (Scrolling)

When the layout is Locked, you can freely scroll the canvas by dragging anywhere on the background — your finger or mouse moves the view without affecting any elements. This is the safest way to navigate a zoomed canvas.

Best practice: Zoom in to work on fine detail (small text, precise alignment), then zoom back out to see the full composition before exporting.

Rulers and Guides

The editor displays a horizontal ruler across the top and a vertical ruler on the left side of the canvas. You can drag from either ruler onto the canvas to place a guide line — a non-printing alignment reference line.

  • Place a guide: Click and drag from the top ruler (horizontal guide) or left ruler (vertical guide) onto the canvas.
  • Move a guide: Click and drag the guide line to reposition it.
  • Delete a guide: Hover over a guide to reveal the ✕ delete button, then click it.

Rulers and guides are hidden on mobile devices.

29. Reset to Original

The 🔄 Reset button in the Tools Drawer restores the menu to its original template — exactly as it was when first delivered to you. All custom edits, text changes, image placements, and style changes are removed.

Warning — Cannot Be Undone: Reset to Original cannot be undone with the ↺ Undo button. Once confirmed, all your edits are permanently cleared. Only use Reset when you intentionally want to start fresh from the original template.

Reset Confirmation

When you click Reset, a confirmation dialog appears asking you to confirm before anything is changed. Read the dialog carefully before confirming. Click Cancel if you clicked Reset by accident.

When to Use Reset

  • You want to completely start over with a clean template
  • Your layout has become too cluttered or confused to repair through editing
  • You are starting a new seasonal menu version from scratch

In all other cases, use ↺ Undo for individual mistakes and 📂 Load Session to return to your last saved state.

30. Cross-Device Syncing

Menu Editor Pro V2 uses server-side persistence — your saved sessions are stored securely on the server, not just in your browser. This means you can work on any device and always have access to your latest saved version.

How to Continue on Another Device

  1. On your current device, click 💾 Save Session to save all current work to the server.
  2. Open your editor link on the second device (phone, tablet, or another computer).
  3. Open the drawer and click 📂 Load Session.
  4. Your complete menu — all text, images, styles, and positions — loads exactly as saved.
Tip: When you open the editor on a new device for the first time, it automatically loads your most recent local browser backup if one exists. Still, always click Load Session to confirm you have the latest server version.

What Gets Synced

  • All text content and styles
  • All element positions and sizes
  • All layer settings (visibility, lock state, opacity, role)
  • All image placements and positions
  • Your uploaded image library (stored in the Asset Tray)

32. Troubleshooting

This section covers the most common issues you may encounter and how to resolve each one quickly.

Problem Cause Solution
Ctrl+Z undid the whole text element, not just one characterExpected behavior — Ctrl+Z during active text editing is browser-native undoPress Ctrl+Z again while still in text edit mode to undo individual characters
Lasso selection not workingLayout is LockedSwitch to 🔓 Layout Unlocked, then drag on empty canvas area
Alignment tools not visible in ARRANGE tabOnly one element selectedSelect 2 or more elements using Shift+click or lasso to reveal alignment tools
Added rectangle appeared off-screenOld bug — fixed in Bug Batch 6Update to latest version — rectangles now always appear at viewport center
Canvas not fitting screen on loadOld bug — fixedCanvas now auto-fits to screen width on every load
Save button looks different / highlightedDirty state indicator — you have unsaved changesClick 💾 Save to save your work

I cannot click on an element

Most likely cause: The layout is Locked. Click the 🔒 Layout Locked button to switch to 🔓 Unlocked mode, then try clicking the element again.

Second possible cause: The element has its Lock toggle turned on in the LAYER tab. Open the Layers Panel in the drawer, find the element's row, and click its 🔒 icon to unlock it.

I accidentally moved an element to the wrong position

Click ↺ Undo Last Change in the top header bar (or press Ctrl+Z) immediately. The element will return to its previous position. The undo system tracks up to 50 steps, so you can step back through several accidental changes if needed.

My text edits are not showing up

Make sure you double-clicked the text element to enter editing mode (you should see a blinking cursor). Single-clicking only selects the element without entering edit mode. Also confirm you clicked the canvas background to commit your changes after typing — text edits are confirmed when you exit the text element.

The exported PNG looks blurry or low quality

The exported file is always generated at full 300 DPI resolution regardless of how it looks on screen. If the image appears soft when viewing on your computer, try opening it in a photo viewer that displays at 100% zoom. Very large PNG files at 300 DPI appear small on screen because the screen has fewer pixels per inch than the file. Send the file directly to your printer — it will print crisply.

A hidden element is appearing in my export

Check the element's visibility in the Layers Panel. The 👁️ icon must be toggled to 🙈 (hidden) for the element to be excluded from export. If the icon shows as 👁️, the element is visible and will appear in the export.

The editor is running slowly or appears frozen

Try clicking the ↺ RELOAD button in the top header bar. Save your work first before reloading — any unsaved changes will be lost. After reloading, use Load Session to restore your last saved state.

I lost my changes after closing the browser

Changes are only permanently saved when you click the 💾 Save button. The editor does maintain a local browser backup, but this can be cleared by browser updates or cache cleaning. Always click Save before closing the browser. Best habit: Save after every significant edit.

Save or Load is failing or hanging

This usually indicates a temporary internet connection issue. Check your connection. The editor will retry automatically. If the problem persists, try the RELOAD button, then attempt Save again. The local browser backup protects your most recent work during connection interruptions.

An image I uploaded is not appearing on the canvas

Check the Layers Panel — the image may have been placed but is hidden (🙈) or has Opacity at 0%. Also check that your image file is a supported format: JPG, PNG, WEBP, GIF, or SVG. Very large files may take a moment to process — wait a few seconds and check again.

I cannot find the Selection Bar — it disappeared

The Selection Bar only appears when an element is selected. Click or tap any element on the canvas to bring it back. If you previously dragged it off-screen, try reloading the page (save first) to reset the toolbar position.

33. Best Practices

These habits will protect your work, keep your menu looking professional, and make editing fast and frustration-free.

Saving Habits

  • Save after every section of work. Update a group of prices → Save. Add a new item description → Save. Move an image into position → Save.
  • Save before closing the browser — even if you are "just stepping away for a minute."
  • Save before switching devices. Server-side save is the bridge between your phone and your computer.
  • The 💾 Save button is in the top header bar — always one tap away.

Layout Lock Habits

  • Keep Layout Locked by default. Only unlock when you need to drag something. Re-lock immediately after.
  • On mobile especially: Locked mode prevents dozens of potential accidental repositioning errors.
  • Text editing (double-click to type) works in both Locked and Unlocked mode — you never need to unlock just to edit text.

Typography Best Practices

  • Keep section headers larger (28–36px) and item names smaller (16–22px) for clear visual hierarchy.
  • Use Center alignment for titles, prices, and featured items. Use Left alignment for descriptions and lists.
  • Limit your menu to 2–3 font choices maximum for a clean, professional look.
  • Use Letter Spacing (positive values) on headers for an elegant, premium appearance.
  • Increase Line Height (1.4–1.6) for paragraph descriptions to improve readability.

Image Best Practices

  • Use PNG with transparency for logos — the editor auto-trims the transparent edges.
  • Upload images at the highest resolution you have — the editor handles large files well.
  • Use the Opacity slider in the LAYER tab to fade decorative images that should not compete with text.
  • Lock any image that should never move (background frame, watermark) using the 🔒 Lock toggle.

Layer Organization

  • Give your elements meaningful names in the LAYER tab ("main-title", "price-col-1", "logo") for easy identification in the Layers Panel.
  • Use the Layers Panel to select hidden or stacked elements instead of trying to click them on the canvas.
  • Set background frames and decorative borders to Role: Background + Locked so they can never be accidentally moved.

Before Exporting

  • Review all text for spelling errors — zoom in on each section.
  • Check that all prices are correctly updated.
  • Verify that no elements you want visible are accidentally hidden (check the Layers Panel).
  • Save your session — Export auto-saves, but it is good habit to save manually first.
  • Export, then open the downloaded file and zoom to 100% to inspect quality before sending to print.

Generating an Image

  1. Expand the 🖼️ Generate Image section.
  2. Enter a prompt describing the image you want (e.g., a beautifully plated grilled salmon with lemon and herbs, restaurant lighting).
  3. Optionally click ✨ Enhance Prompt to have the AI improve your description for better results.
  4. Choose an Aspect Ratio and Style from the dropdowns.
  5. Optionally enter a Negative Prompt to exclude unwanted elements.
  6. Enhance Prompt — Before generating, click the "Enhance Prompt" button to automatically rewrite your prompt into a more detailed, cinematic, AI-optimized version. The enhanced text replaces your original prompt in the text field. You can edit it further before generating.

  8. Click Upload to Cloudinary to host the image on your Cloudinary CDN, or click Place on Canvas to add it directly to your menu.

Generating a Video

  1. Expand the 🎬 Generate Video section.
  2. Optionally upload a Reference Image to guide the video's starting frame.
  3. Enter a prompt describing the video motion (e.g., steam rising from a bowl of ramen, slow cinematic pull-back).
  4. Use ✨ Enhance Prompt for better results.
  5. Configure Duration, Resolution, and Camera Motion.
  6. Adjust Creativity vs. Prompt Fidelity (CFG Scale) — lower values are more creative, higher values follow the prompt more strictly.
  7. Enhance Prompt — Before generating, click the "Enhance Prompt" button to automatically rewrite your prompt into a more detailed, cinematic, AI-optimized version. The enhanced text replaces your original prompt in the text field. You can edit it further before generating.

  9. Once ready, the video plays in the panel. Click Send to Viewer to automatically populate the matching Viewer Panel video URL field based on your chosen resolution.

The Enhance Prompt Feature

The Enhance Prompt button sends your text to the backend where it is augmented with professional food photography modifiers. For images, it adds terms like professional food photography, soft natural lighting, shallow depth of field, 85mm lens. For videos, it adds cinematic food video, slow motion, professional lighting, 4K quality. You can edit the enhanced result before generating.

How AI Images Are Placed on the Canvas

When you click Place on Canvas, the image is first uploaded to your Cloudinary CDN (if not already). A new image element is created at the center of your current viewport, sized at 300×300px. You can then move, resize, and style it like any other element. The element is placed using the standard V2 image element schema.

Important: AI-generated content may be subject to the respective service's terms of use. Review each platform's policies before using generated content commercially.

AI Gallery

The AI Gallery tab (fourth tab in the left sidebar) shows all previously generated AI content for your menu:

  • Generated Images — all images you created with Stability AI or Kling AI and saved to assets. Click any image to place it on the canvas.
  • Generated Videos — all videos generated with Kling AI, organized by slot (Hero, Left, Right). Each video card shows apply buttons for all three viewer slots so you can re-apply any previous video without regenerating.

Use the AI Gallery to retrieve and reuse any previously generated content without running a new generation job.
