## 1. Project Identity

**Product Name:** Dine In Menu Editor Pro  
**Client / Owner:** Not Your Mama's Kitchen (NYMK) — restaurant brand  
**What it is:** A browser-based, professional-grade layered menu layout editor. Allows non-designers to update a visually complex restaurant menu safely while preserving print accuracy and layout integrity.

**Core promise:**
- Fast on mobile
- Safe for non-technical users
- Reliable across devices
- Deterministic print-quality output (12in × 18in @ 300 DPI)
- Strong brand presentation
- Minimal accidental layout damage

**This is NOT just a text editor.** It is a controlled layout engine with server-backed continuity and a professional export pipeline.

### Backend Routes (app.py)
| Route | Behavior |
|-------|----------|
| `GET /` | Serves index.html with `Cache-Control: no-cache, must-revalidate` |
| `GET /<path:path>` | Serves static files. `.ttf/.js/.jpg/.jpeg/.png/.webp` get `Cache-Control: max-age=604800, public` |
| `GET/POST /api/menu` | Load / Save session JSON to Railway Volume |
| `POST /api/menu/reset` | Backs up then wipes menu_data.json |
| `POST /api/upload-image` | Accepts base64 image, saves to /app/data/user_images/ |
| `GET /api/list-images` | Returns list of user-uploaded images |
| `DELETE /api/delete-image/<filename>` | Removes a user-uploaded image |
| `GET /user-images/<filename>` | Serves user images with `Cache-Control: max-age=604800, public` |

### Persistence
- Railway Volume mounted at `/app/data`
- Save file: `/app/data/menu_data.json`
- Backups: `/app/data/backups/menu_data_YYYYMMDD_HHMMSS.json`
- Writes use atomic `.tmp` + `os.replace` pattern
- Frontend has localStorage fallback if server unreachable

## 4. What Was Built Successfully (Full History)

### 4.1 Generator-first architecture
`build_app.py` emits all CSS, HTML, and JS into `index.html`. Python f-string braces are escaped with `{{` and `}}` to avoid collision with emitted JavaScript/CSS braces.

### 4.2 Split-asset load strategy
- `menu-bg-preview.jpg` (lightweight) → used in editor, loaded with `fetchpriority="high"`
- `menu-bg.png` (full resolution) → loaded only during Export Pro PNG
- This solved the LCP problem on mobile

### 4.3 Deterministic export pipeline
- Export renders at 3600 × 5400px (12in × 18in @ 300 DPI)
- Elements rendered in z-order using Canvas API
- PNG pHYs metadata chunk manually injected for true 300 DPI
- Uses `inject300DpiAndDownload()` from `export-utils.js`
- NEVER uses html2canvas or screenshot-style export

### 4.4 Railway-backed persistence
- Server-side JSON on Railway Volume
- Atomic writes with backup rotation
- Frontend retry + localStorage fallback

### 4.5 V2 Layered document model
- docV2 object with version, elements[], settings, editorState
- Elements have: id, type, text/src, x, y, zIndex, opacity, rotation, visible, locked, layerRole, style
- layerRole values: `background`, `content`, `overlay`

### 4.6 Professional UI systems
- Branded modal for Reset confirmation
- Toast notifications for save/load/export/undo
- Smart tooltips (data-help attribute, shown once per session)
- Bilingual in-app manual (EN + ES), loaded from `/manual-en.html` and `/manual-es.html`

### 4.7 Mobile-safe interaction model
- Layout Locked by default on load
- Multi-touch drag suppression (second finger cancels drag)
- Moveable toolbar (drag handle with pointer capture)
- Floating zoom +/- buttons (visible only when unlocked)
- Touch events mapped to mouse event handlers

### 4.8 Undo system
- 30-state history stack (pushState snapshots full elements array)
- Undo via toolbar button or Ctrl+Z
- Text blur commit tracked separately (saves snapshot before change)

### 4.9 User image upload + library
- Upload from device → POST /api/upload-image → served from /user-images/
- Asset tray shows user images with delete (✕) button
- Transparent pixel trimming on upload

## 9. V2 Data Model Contract (Official Schema)

This is the authoritative schema for all future layered editor work. Antigravity must treat this as the design baseline. Any deviation requires explicit approval before coding.

### 9.1 Top-Level Document Shape
```json
{
  "version": "2.0.0",
  "documentId": "doc_001",
  "name": "Not Your Mama's Kitchen Menu",
  "canvas": {
    "width": 3600,
    "height": 5400,
    "dpi": 300,
    "unit": "px",
    "backgroundColor": "#f3f3f3"
  },
  "settings": {
    "layoutLocked": true,
    "backgroundLayerLocked": true,
    "snapEnabled": false,
    "gridEnabled": false
  },
  "editorState": {
    "activeElementId": null,
    "selectedElementIds": [],
    "zoom": 1,
    "panX": 0,
    "panY": 0
  },
  "assets": [],
  "elements": [],
  "meta": {
    "sourceTemplate": "nymk-menu-v1",
    "migrationFrom": "1.x"
  }
}
```

### 9.2 Asset Registry Entry
```json
{
  "id": "asset_001",
  "kind": "image",
  "name": "Chicken and Waffles Hero",
  "storage": {
    "originalUrl": "/Images/asset7.png",
    "previewUrl": "https://res.cloudinary.com/.../asset7.webp",
    "thumbnailUrl": null
  },
  "original": { "width": 1800, "height": 1200, "mimeType": "image/png" },
  "tags": ["food", "hero"],
  "createdAt": "2026-03-15T12:00:00Z"
}
```
- `originalUrl` is the export source of truth — NEVER use previewUrl for export
- `previewUrl` is for editor display only (performance)
- Phase 2A only requires `kind: "image"`

### 9.3 Base Element Shape (all elements share this)
```json
{
  "id": "el_001",
  "type": "image|text|shape",
  "name": "Human-readable label",
  "x": 300, "y": 2100,
  "width": 800, "height": 600,
  "rotation": 0,
  "zIndex": 10,
  "locked": true,
  "visible": true,
  "opacity": 1,
  "layerRole": "background|content|overlay"
}
```

### 9.4 Text Element (extends base)
```json
{
  "text": "MAIN ENTREES",
  "style": {
    "fontFamily": "century-gothic-regular",
    "fontSize": 84,
    "fontWeight": 700,
    "color": "#ffffff",
    "textAlign": "center",
    "lineHeight": 1.1,
    "letterSpacing": 0,
    "textTransform": "uppercase"
  }
}
```

### 9.5 Image Element (extends base)
```json
{
  "assetId": "asset_007",
  "fitMode": "contain",
  "crop": null
}
```
- Must reference a valid asset in the assets array
- Export must use `storage.originalUrl` from referenced asset

### 9.6 Shape Element (extends base)
```json
{
  "shapeType": "rectangle",
  "style": {
    "fill": "#000000",
    "stroke": null,
    "strokeWidth": 0,
    "cornerRadius": 0
  }
}
```
- Phase 2A: rectangle only

### 9.7 V2 Contract Rules Summary
- `layoutLocked` defaults to `true` on load
- `backgroundLayerLocked` defaults to `true`
- Export renders elements in ascending `zIndex` order
- Preview URLs NEVER used in export
- Selection state never required for export
- Undo uses full-document snapshots, max 50 states
- Migration: old text items → `type: "text"` elements, version → `"2.0.0"`
